# Memento En-Ru (unofficial fork)

Неофициальный форк [Memento](https://github.com/ripose-jp/Memento), исходная база 2.0.2. Оригинальный разработчик — Ripose. Исходные copyright notices сохранены; новые изменения не приписываются ему автоматически.

Видеоплеер на mpv/Qt: субтитры, поиск английских слов и словоформ, отдельные результаты разных словарей, экспорт в AnkiConnect, русский интерфейс, разбор предложений через буфер обмена и открытие выбранного сайта. Prompt автоматически сервису не отправляется.

Версия предназначена для бета-тестирования на Windows x64. Возможности, доступность словарей и работа внешних сервисов зависят от пользовательских данных и настроек.

Кнопка AI формирует запрос по предложению из субтитров, копирует его в буфер обмена и открывает выбранный сайт. В настройках поиска можно выбрать Gemini, ChatGPT, Claude или Алису и изменить текст запроса. Вставьте и отправьте запрос в чате самостоятельно.

## Сборка Windows

Установите MSYS2 UCRT64, native Windows Git, CMake, MinGW GCC, Make, Qt6 base/declarative/tools/svg, pkgconf, json-c, libzip, mpv, sqlite3, libvorbis. Пакеты устанавливайте через MSYS2 pacman, например с префиксом `mingw-w64-ucrt-x86_64-`. Зафиксируйте версии для воспроизводимости окружения. Сборка требует Qt >= 6.9 и C++20.

Из PowerShell: `./windows/build-release.ps1 -BuildDir ../build-release`. QCoro FetchContent закреплён на `98f23d8d8d67e9e24217d268927faec97c713fb0` (v0.13.0). Для офлайн-сборки клонируйте QCoro отдельно, checkout этого commit и передайте `-QCoroSource <путь>`. Старый build-каталог не нужен. Сеть необходима только для получения зависимостей. По умолчанию скрипт собирает обычную версию для конечных пользователей (`MEMENTO_TEST_PROFILE=OFF`). Для локальной тестовой сборки с прямым запуском изолированного EXE используйте отдельный каталог: `./windows/build-release.ps1 -BuildDir ../build-test -TestProfile`. Такая сборка всегда использует постоянный профиль `Memento-En-Ru-Test`, отдельный от пользовательского профиля. Скрипт включает CTest.

`windows/stage-runtime.ps1 -BuildDir ../build-release -OutputDir ../runtime-local` формирует локальную проверочную среду: windeployqt плюс замыкание PE-import DLL через objdump, без удаления библиотек наугад. Список связей сохраняется в dependency-edges.csv. Динамически загружаемые плагины покрывает windeployqt; полный smoke test всё равно обязателен.

## Пользовательские данные

Словари Yomitan импортируются пользователем через настройки. Они не входят в проект. Закрытые словари, SoundEn.lsa, колоды English.apkg, профили и AnkiConnect не поставляются. Установите AnkiConnect самостоятельно из официального источника и разрешите локальное соединение с Anki. При недоступном AnkiConnect добавление карточки не может считаться успешным.

При первом запуске Memento автоматически добавляет в Audio Sources строки `Lingvo UK` и `Lingvo US`, обе с типом Lingvo LSA и путём `@app/audio/SoundEn.lsa`. `@app/` означает папку рядом с `memento.exe`, поэтому положите свой архив в подкаталог `audio` рядом с программой. Сам `SoundEn.lsa` в дистрибутив не входит. Индекс озвучки встроен в EXE; отдельный TSV-файл не требуется. Индекс восстановлен из старой сборки и должен соответствовать версии архива.

MeCab/IPADIC исключён из базового пакета; для японского поиска нужны отдельные разрешённые данные и конфигурация сборки. Case-insensitive SQLite NOCASE ориентирован на ASCII английский; полная Unicode case folding не заявляется.

## Установка и ручная проверка

Для конечного пользователя: распакуйте папку целиком и запускайте `memento.exe` (или обычный ярлык программы). `.cmd` для повседневной работы не нужен. Не перемещайте EXE отдельно от DLL и Qt-папок. Обычный запуск использует профиль Memento текущего пользователя Windows.

У EXE, собранного с `-TestProfile`, изолированный профиль встроен в программу: для теста достаточно запустить `memento.exe`. Профиль `Memento-En-Ru-Test` сохраняется между перезапусками и сборками и не затрагивает обычный профиль пользователя. Закрывайте предыдущий тестовый экземпляр перед запуском следующей сборки, чтобы две версии не писали в одну тестовую базу одновременно. Для обычного пользовательского EXE не включайте `-TestProfile`; его можно запускать напрямую или через ярлык. Не помещайте в тестовый профиль приватные данные, если планируете передавать папку сборки.

Видео открыть через меню, проверить play/pause/seek/audio, встроенные и внешние субтитры, hover dictionary, пустой результат, два словаря с одинаковым словом, UK/US, смену языка с перезапуском, отправку тестовой карточки в собственный Anki-профиль, отказ при закрытом Anki. Эти интерактивные проверки должны быть отдельно отмечены PASS; unit tests не заменяют их.

Обновление v4 базы до v5 выполняется приложением; перед реальным обновлением пользователь должен сохранить копию своей базы. Автотест использует только временные синтетические базы.
