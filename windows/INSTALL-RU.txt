Memento En-Ru — портативная Windows x64 сборка

Установка
1. Распакуйте ZIP целиком в отдельную папку.
2. Закройте другие запущенные экземпляры Memento, затем запустите memento.exe.
3. Не перемещайте memento.exe отдельно от DLL и папок qml и platforms.
4. Программа использует обычный профиль Memento текущего пользователя Windows.

Пользовательские данные
Словари, конфигурации пользователя, SoundEn.lsa и колоды Anki в архив не входят.
Для Lingvo поместите собственный SoundEn.lsa в папку audio рядом с memento.exe.
Источники Lingvo UK/US уже указывают на @app/audio/SoundEn.lsa. Индекс озвучки встроен в программу, отдельный файл индекса не требуется.
